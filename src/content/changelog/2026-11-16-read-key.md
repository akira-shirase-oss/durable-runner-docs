---
title: Reads need a key, and a read-only key exists
date: 2026-11-16
type: Security
areas: [API, Server]
docs:
  - label: API reference
    href: /api/reference/
---

Listing and inspecting runs now requires a key. Servers can set a second, read-only key that may
list and inspect but is refused (`403`) on submits, cancels, admin routes and spec read-back. For
trusted local tooling, `--open-reads` still opens the two read routes — but only for requests that
arrive on loopback addressed to a loopback Host, so a browser on the same machine cannot be talked
into reading through it. Never place `--open-reads` behind a proxy.
