Everything before this window, in one card: the framed append-only journal with one writer and an
exclusive lock; the engine that dispatches steps to allowlisted HTTP handlers at-least-once under a
single idempotency key and reconciles lost replies by probe; the nine-route HTTP API with its error
envelope; the operator CLI; consistent backups and verified restores; snapshots and compaction;
and the read-mostly Inspector served same-origin. The pages on this site cover each in depth —
start with [Concepts](/concepts/).
