The recovery drill now stops the server with `SIGKILL` in the middle of real submits and
replays the journal afterwards: every acknowledged run came back, zero lost. Frame, snapshot and
index formats are pinned by golden files too, so an accidental format change fails a test instead
of reaching a journal.
